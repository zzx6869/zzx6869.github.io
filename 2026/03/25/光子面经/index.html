光子面经

2026/3/25 面试

基本信息

  • 时间：2026-03-24
  • 轮次：一面
  • 时长：约 40 分钟

面试内容

1. 开场

工作室介绍与自我介绍。

2. 二进制反编译项目

  • 做了什么工作，分工如何
  • 为什么想到用 MCP，之前是否接触过 IDA
  • MCP 是怎么实现的，如何理解 MCP
  • 遇到过什么问题，怎么解决
  • 用过哪些模型

3. C++ 基础

  • 虚函数介绍
  • 虚函数表什么时候生成

4. 浮点数

  • 浮点数精度问题（如 float）
  • 如何存储

5. 内存与对齐

  • 字节对齐：为什么要对齐
  • 给定 struct 判断占多少字节
  • int、long 多少字节（与系统相关）

6. AI 编程 / 工具

  • vibecoding 相关：用过什么
  • Ask、Plan、Agent 模式怎么理解
  • Skills 呢
  • 用过 openspec 吗
  • Claude Code、prompt 怎么写，能否结合项目举例

7. 大模型与 RAG

  • 是否做过语义增强（项目里为什么没用）
  • RAG 相关，怎么实现
  • 有没有自己部署过大模型

8. 图形学与引擎

  • 图形学是否接触过，渲染等
  • UE 是否接触过，有没有实现过引擎里的模块代码

反问

向面试官问了哪些建议、还需要补充哪些知识，以及简历上还有哪些可以展开介绍的内容。
